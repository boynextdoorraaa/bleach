# BLEACH 灵魂人生模拟器

这是一个不依赖后端、可直接部署到 GitHub Pages 的互动网页原型。内容依据项目随附的底层设计文档、事件母库、社交系统和能力体系表转换而来。

## 当前可玩内容

- 自由人生创建与级联随机穿越
- 唯一世界时间线、每月 10 AP 与月末结算
- 月末必定事件：根据本月行动与选择生成后果，并持续推进世界暗线
- 366 个事件节点与 50 个社交事件
- d100 事件检定、双方对抗检定、精神豁免、优势 / 劣势和锁定结果
- 八项 1–100 核心属性：肉体强度、机动反应、破坏力、灵魂抗性、灵源容量、操控造诣、洞察智力、人格意志
- 命中伤害按破坏力 ÷ 4 结算，肉体强度 ÷ 4 减伤；形态解放额外增加 8–15 点伤害
- 能力按攻击、防御、机动、控制、感知、支援、灵源、解放、特殊九类划分
- 每项能力拥有独立属性加成、事件适用权重、发动消耗与熟练度；防御能力直接计入人物有效属性
- 行动成功率、觉醒率、突破率、遭遇率、受伤率及重大事件卷入率实时估算
- 分层地图、路线知识、能力与权限检查
- 35 个原作人物社交模板与四维关系
- 424 条能力资料检索
- 世界压力、因果队列、原作大事件卷入度
- 浏览器本地存档及 JSON 导入/导出

## 本地运行

直接双击 `index.html` 即可使用。建议通过静态服务器运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## GitHub Pages

将本目录内容放到仓库默认分支根目录，然后在仓库的 Settings → Pages 中选择从默认分支根目录部署。

## 数据说明

`data/` 目录是由项目源文件机械生成的浏览器数据包：

- 事件不会被写死在界面中；代码只负责筛选、检定与结算。
- 正史、官方补充、推演和原创能力保留原始证据标签。
- 本项目是非商业同人交互原型，不包含原作图片、音乐或大段台词。
